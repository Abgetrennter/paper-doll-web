# paper-doll-web 纸娃娃换装机（Web 重写版）

「キャラクターなんとか機」v2.10（一款 2010 年代的日语纸娃娃换装工具）的浏览器重写版。
基于对原程序的完整逆向工程（HSP3 字节码反编译 + imgctl.dll 反汇编）实现，
渲染结果与原程序**逐像素一致**，界面为中文，部件名自动还原为正常日文。

原程序信息与逆向过程记录见 [docs/designs/paper-doll-web.md](docs/designs/paper-doll-web.md)。

## 特性

- 纯静态页面，无构建、无依赖、无网络请求——双击 `app/index.html` 即可使用
- 直接读取原程序的 `data\` 素材目录（分层 PNG），素材文件不做任何修改
- 完整复刻原程序逻辑：
  - 16 层图层按原顺序合成，部件同名配对（如 body 键同时驱动素体/服装/服装色三层）
  - 换色管线与 imgctl.dll 逐指令一致（通道交换、伽马、扺色化、色调，含整数舍入方式）
  - 发色 11 档 / 瞳色 8 档 / 肤色 5 档 / 服色 8 档 × 明暗 7 档
  - 饰品最多 6 个，可增删与前后排序，文件名含 (髪)(瞳)(肌)(服) 时继承对应颜色
  - 自动加载 `profile\<角色集>.dat` 存档（与原程序启动行为一致）
- 素材文件名乱码自动还原（Shift_JIS 文件名在 GBK 系统上的历史遗留问题），正常日文命名的角色集同样兼容
- 不依赖系统区域设置：所有编码转换显式完成，任何语言的系统上表现一致

## 使用方法

1. 双击打开 `app/index.html`（Chrome / Edge）；
2. 点击「选择文件」选择原程序的 `data` 文件夹（或包含 `data`、`profile` 的项目根目录）；
3. 选择角色集、部件、颜色，即可换装。

所有数据均在本地处理，不上传任何内容。

## 渲染一致性验证

`test/` 内含一套独立实现的 Python 参考渲染器（直接由反编译规格写出）与自动化比对脚本：

- 与原程序实机渲染对比（PrintWindow 截取预览区）：**0 / 300000 像素差**
- 8 个配置矩阵（3 角色集 × 换色 / 明暗 / 饰品 / 深色背景组合）：**全部 0 像素差**

复现方式见 `test/gen_matrix.py`（需自行准备原程序素材目录）。

## 技术要点（逆向结论）

- 原程序为 HSP3.1 运行时 + 内嵌脚本字节码；合成公式为 HSP3 `gmode 7` 逐字节截断混合：
  `dst = (dst*(255-a) >> 8) + (src*a >> 8)`（a=0 跳过、a=255 直拷），与 canvas 标准混合不同，故自写像素循环
- 换色的「换色」实为 RGB 通道重排：`ReplaceDIB` 参数对 3 取模作通道选择器（0=R, 1=G, 2=B），
  原作者用 255/128 等值的余数编码 11 种发色映射，辅以 `GammaDIB`（千分比伽马）微调茶/橙/粉
- 肤色是乘法（`ShadeDIB`，千分比乘数），明暗滑杆是向灰度插值（权重 306/601/117）
- 素材 PNG 带 gAMA/cHRM 块，浏览器默认解码会做色彩管理导致色偏，因此内置了一个
  最小 PNG 解码器（`png.js`，基于 DecompressionStream），直接输出未预乘的原始像素
- 原程序在中文系统上因文件名编码问题依赖区域模拟器运行；本重写版在载入时显式完成
  GBK→Shift_JIS 的名字还原，从根上消除了该依赖

## 目录结构

```
app/
  index.html      界面与入口
  app.js          状态、目录载入、渲染循环
  paperdoll.js    核心规格：图层顺序、色表、像素原语、合成
  png.js          最小 PNG 解码器（无预乘、无色彩管理）
  codetable.js    乱码名还原表（自动生成，7336 项）
docs/designs/     设计稿与逆向规格
test/             Python 参考渲染器与比对脚本
```
